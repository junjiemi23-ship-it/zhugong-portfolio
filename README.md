# 主公的粮仓

> 个人项目与成果仓库 —— 把学习、实验与创作落到可运行的作品上。

## 简介

「主公的粮仓」是我的个人数字仓库，也是我的公开作品集：这里收录我把技术落到实际场景的作品——自建网页、调研与数据处理、AI 工具应用、公开信息检索与整理。每个项目力求**可运行、可说明、可复用**：既是我的复盘记录，也是向雇主与同行展示学习能力与实践成果的窗口。

本仓库定位为**公开作品集**：展示能独立完成的项目成果；涉及真实个人数据的部分，一律留在私有环境（见「隐私与合规」）。

## 项目分类

| 类别 | 说明 | 状态 |
|---|---|---|
| 节假日特定网页 | **网页开发与交付**：节日/节点主题页、贺卡、倒计时、交互活动页 | 筹备中 |
| 调研数据问卷 | **调研设计与数据处理**：问卷构建、数据采集与清洗脚本 | 规划中 |
| AI 对话平台 | **AI 工具接入与工程化**：对话/助手接入实验与对比 | 规划中 |
| 网络真实资源大数据查找 | **信息检索与结构化整理**：公开资源的检索、聚合与归类 | 规划中 |
| AI 聊天搭子（角色模拟） | **对话系统实验**：基于对话数据的角色模拟（仅含脱敏示例） | 规划中 |

> 注：「AI 聊天搭子」涉及对话数据，公开内容仅限方法论与脱敏示例；原始数据不进入本仓库。

## 隐私与合规说明

- 本仓库**不含任何真实个人隐私数据**：他人聊天记录、问卷原始应答、API Key / 密码等一律不提交。
- 涉及真实人物对话数据的实验，原始数据保留在**私有仓库或本地**；公开部分仅含脱敏示例与方法说明。
- 使用本仓库内容时，请遵守相关平台服务条款与数据保护相关法律。
