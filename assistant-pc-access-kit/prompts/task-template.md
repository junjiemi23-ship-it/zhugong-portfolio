# 任务指令模板

给助手的指令越结构化，活干得越利索。复制下面这份，填上 `[占位符]` 就能用。

```markdown
## 目标（一句话）
[你要它最终交付什么]

## 背景（它需要知道什么）
- [相关的现状、已有的结论、去哪找资料]

## 执行层
- [ ] L0 助手云电脑可独立完成
- [ ] 需要 L3 我的 PC（说明为什么必须在 PC 上干）

## 约束（不做什么）
- [红线：不花钱 / 不对外发消息 / 不动XX账号，先列出来]

## 验收标准（怎么算做完）
1. [可验证的标准一：比如"每天新精选 ≥ 11"]
2. [可验证的标准二]
3. [证据要求：做了什么、依据是什么]

## 汇报格式
- 结论先行（一句话：成了 / 没成 / 卡在哪）
- 证据（链接、数据、截图）
- 风险和下一步（需要我拍板的事单独列）
```

## 使用说明

1. **目标一句话**：说不清目标就别下指令，先想清楚。
2. **约束先行**：把"不要做"的写在前面，比事后救火便宜。
3. **验收标准要可验证**：能量化就量化（数量、时间、链接），不能量化的写"谁确认"。
4. **多步骤任务**：要求它按"派发 → 跟踪 → 验收 → 汇报"四步走，每步留痕。
5. 验收方法论进阶见 [agent-dispatch-kit](../agent-dispatch-kit/prompts/acceptance.md)（独立第二双眼睛打分）。
