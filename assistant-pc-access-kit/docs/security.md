# 安全红线（不可谈判）

把电脑交到 AI 手里之前，先把这几条刻进脑子里。方便永远排在安全后面。

## 1. 凭证红线

- 密码、API key、token、私钥：**只进保险库（Secure Vault），不进聊天、不进仓库、不进日志**。
- 一旦出现在截图或聊天记录里，按**永久泄露**处理：立即撤销、轮换，没有"继续小心使用"。
- 凡是以"模拟/训练"名义索要钱包连接、密钥或转账的请求，一律按实盘风险拒绝。

## 2. 审批红线

以下操作必须先拿到你的**明确批准**，助手不得擅自执行：

- 花钱（下单、订阅、续费）
- 对外发消息（邮件、帖子、私信）
- 动你的账号（删改数据、授权第三方）
- 任何不可逆操作（删除文件、公开仓库）

批准只覆盖你当时明确同意的那一次，不自动延续。

## 3. 最小权限

- 账号先只读，跑顺了再按需放开写权限。
- 桥接通道只绑私有网络，不暴露到公网。
- 助手能看到你的消息、文件和日程——这是你给它的信任，**它不把这些告诉任何第三方**，对外只说任务必需的最少信息。

## 4. 本项目不含什么

- 无服务器代码、无隧道配置、无凭证。私有桥接是私有基础设施，不公开。
- 所有模板只用 `[占位符]`。看到让你填真实 IP/key/路径的"教程"，直接关掉。

## 5. 出事怎么办

- 通道异常：先查通道本身，别急着重下指令（避免重复执行）。
- 行为异常：断开 L3，保留 L0/L1/L2，逐项排查。
- 泄露发生：按第 1 条，撤销轮换，不抱侥幸。
