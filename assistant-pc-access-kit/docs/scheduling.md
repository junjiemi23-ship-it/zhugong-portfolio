# 定时任务模式：一次配置，永久在线

定时任务是"助手"两个字的含金量：你睡觉，它干活。

## 心智模型

把定时任务当成**数字员工的排班表**：什么时间、干什么事、做到什么标准、结果送到哪。排一次，它天天照做。

## 一个真实例子：AI 新闻监控

- 每天 5 次：早上 9:10 完整日报；11:10 / 13:10 / 16:10 / 20:10 快讯
- 每次触发：拉取信源 → 评分筛选 → 独立核验 → 推送
- 福利类最高优先级；没达到推送标准的，快讯轮次保持安静

## 打扰纪律

1. **没达到标准就安静**：定时任务不是定时打扰。
2. **异常告警一天最多一次**：同一问题不重复吵你。
3. **静默失败也要留痕**：没产出时，日志里记一笔，方便你事后查。
4. **验收期冻结配置**：新任务先跑 2 天看数据（准时率、可用率），达标再转正。

## 从第一个任务开始

1. 选低风险、高频、结果可验证的任务（资讯推送、定时提醒、数据汇总）。
2. 写清四要素：**时间、内容标准、推送去向、安静条件**。
3. 跑 2 天，看数据，再决定加第二个。

任务指令怎么写，见 [任务指令模板](../prompts/task-template.md)。
