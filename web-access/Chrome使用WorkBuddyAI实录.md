# 如何在 Chrome 上发现和使用 WorkBuddy AI

> 主题：普通用户如何在浏览器里找到、上手并高效使用 WorkBuddy AI（含国际版与国外 AI 模型的使用说明）
> 场景：Chrome 浏览器 / WorkBuddy（国内版 + 国际版）
> 整理：2026-08-19

---

## 📌 作品简介（30 秒看懂）

**解决什么问题**：很多用户知道有各种 AI 助手，但不知道「怎么发现一个能干活、能执行任务的 AI 助手」「装好之后怎么让它连上网查资料」「怎么用上国外的 AI 模型」。

**怎么意识到这个问题**：日常使用中，「AI 助手不能访问网页/不能登录态复用/只能聊天不能执行」是高频吐槽；而 WorkBuddy 这类能执行任务的助手，入口和使用方式很多人并不清楚。

**怎么解决**：① 发现入口：在 Chrome 搜索官方站点/应用商店找到 WorkBuddy（国内版/国际版）；② 上手：注册登录、新建任务、让它读文件/查资料/执行脚本；③ 接入网络：用「Chrome 登录态复用 + 分流」让它像真人一样上网（详见 `web-access/WorkBuddy-Chrome访问通道实战记录.md`）；④ 使用国外 AI 模型：通过国际版内置模型或自定义 API 接入（详见第五节）。

**最终效果**：从「只会聊天」到「能联网查资料、能执行任务、能切换多模型」的完整上手路径。

## 一、背景与目标

目标：给零基础用户一条「在 Chrome 上发现并上手 WorkBuddy AI」的路径，覆盖：

1. 在哪里找到、怎么安装/打开；
2. 第一次使用怎么配置（登录、模型选择、工作区）；
3. 怎么让它联网查资料、复用 Chrome 登录态；
4. 怎么使用国外 AI 模型（国际版能力）。

## 二、发现与安装（Chrome 场景）

### 入口 1：官方站点

- 打开 Chrome，搜索「WorkBuddy」官方站点：
  - **国内版**：`workbuddy.cn`（微信/国内账号体系）
  - **国际版**：`workbuddy.ai`（Gmail / Google 登录，内置国际模型）
- 认准官方域名，避免下载到仿冒软件。

### 入口 2：应用商店 / 扩展

- 在官方应用商店搜索 WorkBuddy 客户端（国内版 / 国际版），安装后首次启动。

### 入口 3：直接对话

- 打开后按引导新建会话，选择模型：
  - 国内版常用：Hy3、GLM、DeepSeek 等；
  - 国际版内置：GPT-5.x、Gemini 等（见第五节）。

## 三、上手：让它开始干活

### 基础配置

| 配置项 | 说明 |
|---|---|
| 登录 | 官方账号登录（国内版/国际版账号体系不同） |
| 模型选择 | 按任务选：日常问答用均衡模型，长任务用 1M 上下文模型 |
| 工作区 | 指定一个文件夹作为项目工作区，让它读写文件 |
| 联网权限 | 需要时授权访问 Chrome 登录态 / 网络 |

### 常用命令（示例）

```text
# 让它读资料
读取 D:\AI交流\待处理-xxx.md 并给出解答

# 让它执行任务
帮我新建一个项目目录，写一个 Python 脚本并运行

# 让它联网查资料
搜索「腾讯云免费试用」的最新官方入口，并给出到期注意事项
```

## 四、让它像真人一样上网（登录态 + 分流）

核心：默认的 AI 助手「看不到」你日常 Chrome 的登录态。解决办法见仓库 `web-access/WorkBuddy-Chrome访问通道实战记录.md`，要点：

1. Chrome 官方开关 `chrome://inspect/#remote-debugging` 勾选「启用远程调试」，登录态自动复用；
2. 用 Clash 规则分流：国内站直连、海外站走代理（选 TCP/vless 节点，避开 UDP 被干扰的坑）；
3. 重启电脑后开关会复位，需重新勾选一次。

## 五、使用国外 AI 模型（国际版能力讲解）

### 1. 为什么能用到国外模型

WorkBuddy **国际版**（`workbuddy.ai`）账号体系与国内版独立，客户端/网页版直接内置海外模型服务，请求由国际版后端转发，不需要你自己搭梯子就能在对话里选用 GPT、Gemini、Claude 等。对于需要接自有模型服务的场景，还支持「自定义 API」：填入模型服务地址与 Key，把任意兼容 OpenAI 协议的模型接到工作台里。

### 2. 国际版接入方式

| 方式 | 怎么接 | 适合 |
|---|---|---|
| 国际版内置模型 | 用 `workbuddy.ai` 登录即自带，模型下拉直接选 | 绝大多数用户，开箱即用 |
| 自定义 API | 设置里填「模型服务 Base URL + API Key」，选兼容协议模型 | 已有模型服务/想接特定模型 |

> 国际版登录用 Gmail / Google 账号；国内版用国内账号。两者数据与工作区相互独立，按需切换登录即可。

### 3. 常用国外模型与适用场景

| 模型 | 擅长 | 适合做的任务 |
|---|---|---|
| **GPT-5.x**（OpenAI） | 通用复杂推理、长文写作、代码、英文 | 方案设计、英文润色、跨语言任务、综合问答 |
| **Gemini**（Google） | 超长上下文、多模态、谷歌生态 | 长文档摘要、图片/表格理解、大批量资料梳理 |
| **Claude**（Anthropic） | 严谨代码、长文档、安全对齐 | 代码审查、文档撰写、需要稳妥表述的任务 |
| **Grok** 等 | 实时信息、风格鲜明 | 时效话题、轻松对话 |

选择原则：**先想任务类型，再选模型**——推理与写作看 GPT/Gemini，代码与长文看 Claude，超长资料看 Gemini 的大上下文。不要默认只用某一个，按任务换模型是常态。

### 4. 切换方法

- **同会话内切换**：对话界面模型下拉直接换，切换后保留当前对话历史，可继续聊；
- **换会话**：新会话不继承上一段对话历史，但本地**记忆文件不丢**（长期偏好、项目约定仍在）；
- **自定义模型**：在设置里添加并保存后，会出现在模型列表，随时选用。

### 5. 网络要求

- **国际版内置模型**：连通性由国际版后端处理，客户端本身不需要你额外配置代理；只要能正常打开 `workbuddy.ai` 即可对话。
- **让 AI 联网查公开网页 / 复用 Chrome 登录态**：走第四节的 `chrome://inspect` + 规则分流通道，海外站点经代理出口、国内站直连，避免数据中心 IP 被风控。
- **自定义 API 的自建通道**：若模型服务部署在海外，调用时同样需要可达的网络出口，按服务商要求配置。

### 6. Key 安全（重点）

- **Key 只存在本地安全配置 / 环境变量里**，不要写进聊天、不要写进文件、不要截进图、不要发到群里或帖子；
- 订阅链接、API Key 等凭证都属于敏感信息，任何「复制给 AI 看」的行为都不要做；
- 怀疑泄露时第一时间在服务商后台**吊销并轮换**；
- 多人共用机器时，退出账号、不勾选「记住 Key」。

## 六、常见问题（FAQ）

| 问题 | 答案 |
|---|---|
| AI 助手打不开网页？ | 检查联网授权与 Chrome 调试开关是否启用 |
| 切换模型后上下文还在吗？ | 同一会话内切模型保留对话历史；换新会话只丢对话历史，记忆文件不丢 |
| 免费额度/费用怎么看？ | 以客户端用量面板为准，模型窗口与剩余一目了然 |
| 国外模型要自己弄代理吗？ | 国际版内置模型不需要；让 AI 联网查资料才走第四节的 Chrome 通道 |

## 七、结论

- 发现：官方站点/应用商店是唯一可信入口（国内版 `workbuddy.cn` / 国际版 `workbuddy.ai`）；
- 上手：登录 → 选模型 → 指定工作区 → 下指令；
- 上网：chrome://inspect 复用登录态 + 规则分流，让 AI 像真人一样查资料；
- 国外模型：国际版内置开箱即用，自定义 API 接自有模型；按任务选模型，Key 只存本地不外露。
