# 从零搭一套二手数码套利监控：本机 MVP → 免费云服务器 7×24 → 微信推送

> 实战记录 · 2026-08 · 个人项目（zhugong-portfolio）

## ① 解决什么问题

二手数码「低买—翻新—高卖」的套利逻辑很简单：低价收一台有故障但可修的机型，换屏/换电池翻新后高价卖出。但它有三个现实痛点：

1. **人肉盯价太费时间**：闲鱼、拍机堂、转转的低价机会稍纵即逝，靠手动刷新会错过大量候选；
2. **新手容易踩坑**：高价收到 ID 锁、进水主板坏、来路不明的机器，直接砸在手里；
3. **成本算不清**：零件价格、运费、平台手续费不算清楚，忙活半天发现白干。

本项目不解决"怎么修机器"（那是另一门手艺），而是解决"**在什么条件下值得入手**"的决策问题：搭建一套 7×24 的监控流水线，只在「价格低 + 可修概率高 + 零件成本可控 + 保守净利 ≥ 200 元」时推送到手机提醒。

## ② 怎么意识到 / 发现这个问题

起因是一句很普通的话："要不要买台云服务器跑监控？"

排查过程中发现了一系列"想当然"的坑：

- 以为腾讯云资源有现成的 MCP 连接器，实际在 AI 助手环境里走的是 **tccli 命令行 + OAuth**；
- 查了全部地域的实例，结果 **0 台**——"领了免费资格"和"真的创建了机器"是两回事；
- 于是把"先买服务器"改成了"**先本机零成本跑通，再上免费服务器**"，一分钱没花先把流程验证了。

## ③ 怎么解决的

### 阶段一：本机零成本 MVP

用 Python + SQLite 搭了一条最小流水线：

- `collector.py`：采集器（先接 mock 数据验证流程，真实采集留本机、低频防反爬）；
- `analyzer.py`：规则引擎——机型/故障识别、**红线硬淘汰**（ID 锁、进水主板坏、无图无描述、来路不明）、**配件排除**（卖配件≠故障整机，两层信号防误伤）、零件成本估算、利润模型；
- `pricing.py`：参考价目表（**2026-08-20 已替换为真实市场价**，来源带日期，见文末附录）；
- `db.py`：SQLite 存快照与历史价；
- `notifier.py`：Server酱 微信推送（无 Key 时降级本地日志）；
- `main.py`：编排全流程。

判定规则（可写死为配置）：净利 ≥ 200 元才推；零件成本超过净利 50% 降级；单笔预算 ≤ 1000 元。

### 阶段二：免费云服务器 7×24

腾讯云 Free Tier（免费产品体验）找到**个人认证免费 CVM**（2 核 2G / Ubuntu 22.04 / 0 元 1 个月），部署要点：

- **SSH 密钥登录**（ed25519，私钥权限 600），验证后禁用密码登录；
- **安全组只放行 TCP 22 入站**，出站全开（推送只需出网）；
- **crontab 每 6 小时 + 随机 ±30 分钟抖动**，失败写日志并推告警（防静默失败）；
- **每周自动备份 SQLite**，保留 30 天；
- **到期前 3 天双保险提醒 + 关闭自动续费**，到期决定续费或销毁，不花冤枉钱。

> 架构定稿（Codex 审查结论）：真实采集必须在本机（服务器机房 IP 易被平台风控），本机采集→分析→推送全链路都能做，**免费服务器到期后直接释放**，不做"本机→服务器"同步的复杂度。

### 阶段三：微信推送

Server酱（ServerChan）把监控结果直达手机微信：候选商品、判定理由、预估净利，一条消息说清，人只需要做"最终拍板"。

## 避坑清单（可复用）

1. **腾讯云资源在 AI 助手环境 = tccli CLI + OAuth，不是 MCP 连接器**——搜不到工具属正常，别怀疑没授权。
2. **"领了免费资格" ≠ "创建了实例"**——先只读查询确认，别急着买。
3. **沙箱装包失败**（安全删除拦截）：禁用沙箱 + `--no-cache-dir`，装进隔离虚拟环境。
4. **安全组三坑**：改规则要传当前 Version（自增）；删除默认规则要带 Action 字段；IPv6 用 `Ipv6CidrBlock`；顺序=先加白再删黑，别把自己挡在门外。
5. **免费档以 Free Tier 通用入口为准**，活动页专属链接可能不可领。
6. **到期防扣费**：创建当天就建"到期前 3 天"提醒 + 关自动续费 + 手机日历双保险；到期前定"续 or 销毁"。
7. **Ubuntu 首次登录**：默认用户是 `ubuntu`（非 root），sudo 提权；私钥权限必须 600。
8. **cron 不认环境变量**：写绝对路径或首行设 PATH；输出重定向到日志；时区设北京时间。
9. **tccli 必带 `--region`**，否则查不到跨地域资源。
10. **信息红线**：公网 IP、实例 ID、推送密钥**一律不进公开仓库**；密钥放 `.env`/配置文件且权限 600。
11. **搜索词会引来配件商**：搜「iPhone11 电池/屏幕」命中大量卖电池/屏幕的**配件卖家**（20–108 元），首次真实采集 21 条"可推"全是配件、净利虚高 6 倍（把 30 元电池当整机算）。负向规则用**两层信号**防误伤：强信号（不是整机/只卖/单卖/总成/拆机件/装机即用/适合换电池/批发/起拍等）任一命中即排除；弱信号（电池/屏幕/主板/循环/mAh/容量/健康/拆机）需 ≥2 条且价 <200 才排除；价格 <100 直接排除（配件价带）。

## 合规与诚实

- 只监控公开挂牌信息，不提供绕过反爬的细节；频率低频、带随机抖动，尊重平台规则；
- ID 锁/激活锁机器**一律拒收**（法律风险，也是保护自己）；
- 本文价格基于 **2026-08-20 公开市场行情**（见附录），个别未核实项已标注，二手价随行情波动需定期校准；不承诺任何收益，套利有翻车风险，先小批量试跑。

## 附录：2026-08-20 真实价格调研速查

> 完整报告（含全部来源链接与逐项区间）：`价格调研-2026-08-20.md`（项目仓库内）。三类口径严格区分：**回收价**=平台收机器的出价（低买参考）；**挂牌价**=个人/平台挂卖价（高卖参考）；**零件价**=维修更换成本。

| 机型 | 保守收购价上限（收故障机） | 保守售价（翻新后） | 零件成本合计 | 单台预估净利 | 置信度 |
|---|---|---|---|---|---|
| **iPhone 11 128G** | **700**（仅屏幕完好机；碎屏≤500） | **1000–1200** | 只换电池 200–280 | **100–300** | 高 |
| **iPhone X 64G** | **350**（仅屏幕完好机；碎屏≤250） | **700–900** | 只换电池 150–250 | **150–400** | 中 |
| **红米 Note12 5G** | **250** | **450–550** | 换屏+电池 300–450 | **0–50（不建议）** | 高 |

**关键操作建议**：

1. **只收"屏幕完好、电池老化"的机器**。碎屏机换屏成本吃掉全部差价；iPhone 换第三方屏后走平台回收会被再折价 300–500 元（咸宁日报 2026-07-23），"修不如不修"，翻新后走闲鱼个人渠道出售。
2. **iPhone 11 是首选套利机型**：流通量大、价差稳、零件便宜、iOS 仍受支持。
3. **iPhone X 慎做**：已停产、官方维修停止、系统止步 iOS 16，流动性风险高。
4. **红米 Note12 标准版不建议做**：价差被零件成本吃掉；若坚持做红米选 Note12 Turbo 且收购价压到 350 以下。
5. 售价取区间下限作为监控触发价（保守）；触发价建议每日校准一次。

**未核实项（替换前需实测）**：爱回收/转转官网单机精确估价（需登录机况）；iPhone X 尾插排线大陆实时价（仅台湾行情量级参考）。
